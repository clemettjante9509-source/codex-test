# 初一高效作业批改 & 提分工具

This repository is used to test Codex cloud environment。

面向数学、语文、英语、地理、生物、历史、道德与法治的本机网页工具。帮助学生抓采分逻辑、理解关键词、用5分钟补漏，保留十项固定报告和逆向学习引导。

## 访问和操作

需要 Python 3.10 或以上，无需安装第三方依赖。

```bash
git clone https://github.com/clemettjante9509-source/codex-test.git
cd codex-test
python3 server.py
```

在**运行命令的电脑**浏览器地址栏输入 `http://127.0.0.1:8000`。GitHub 仓库地址不是运行中的网页。云容器内运行仅用于本机验证；本项目没有发布公共网站。服务器默认只监听本机；不要直接暴露到公网，当前没有多用户登录和访问控制。

1. 选择科目，输入原题和学生答案。
2. 点击「载入历史例题」可立即试用。其他开放题请填写参考答案、教材章节、教师采分点；有模型配置时可选择模型辅助。
3. 点击「开始批改」，下方显示十项报告。精简模式减少讲解文字，保留采分点、步骤及完整结构。
4. 预评分请核对每条分数、判定和错误类型，点击「确认评分」。确认错误类型 C 后，可筛选只看答题框架缺失题。
5. 错题自动进入本机错题本，待复核题与已确认题分别标注。确认正确后退出错题清单。连续两题同科目、同完整考点且预判非正确时合并展示；中间出现正确题会中断合并。未知考点不合并。
6. 筛选科目、完整考点或 A/B/C/D，导出考点与变式题 Markdown 清单（附答案及采分点）。

采分点格式：

```json
[
  {"text":"促进农业：奖励耕织","keywords":["奖励耕织","奖励耕种"],"score":2},
  {"text":"增强战斗力：奖励军功","keywords":["奖励军功","按军功授爵"],"score":2}
]
```

一条对应一个独立得分点；数组中的关键词是同义替代，命中其中一个表示覆盖该点。必须同时满足的条件请拆为不同采分点。可填写一道针对弱项的变式题、答案和采分点。默认历史例题有具体变式；其他题未填写时提供反向改问法的开放练习，须教师核对，不能把它当成已验证的标准变式答案。

## 准确性边界

- **采分点模式**：可离线用于七科，但只是关键词覆盖预评分。不能可靠识别所有否定、矛盾、同义改写和因果关系，始终待复核。不能用覆盖分直接替代正式考试成绩。
- **客观题精确模式**：比较参考答案，忽略大小写、空白与首尾句号。仅适用于需要这些规范化规则的单词、选项、数值等短答案；不判断数学等价式、证明过程、作文或复杂语义。精确不一致也可人工改分。
- **模型辅助模式**：分析七科题目、过程、采分点、变式及短时补漏；分数求和、判定与证据原文经过程序校验，结果始终待复核。模型仍可能出错，温度为0也不能保证正确。不提供模型时，不会伪造全科语义批改结果。
- 缺少采分点且没有配置模型时返回提示，不生成成绩。未知教材章节明确待核对，不凭空声称适配某一教材版本。
- A/B/C/D 根源需要师生判断，不把少写一个词直接归为某类能力问题。正确题不强行归错。
- 地理、生物、历史、道法内置各自答题维度，并按原因/影响/意义/措施/特点选择框架。只记关键词及关系，其余重在理解。

当前没有经过大规模教师标注数据集评估，**不能承诺接近满分的批改准确率**。建议由教师持续对照学校评分标准复核。

## 可选模型接入

服务器进程读取：

| 变量 | 用途 |
| --- | --- |
| `GRADING_API_KEY` | 模型密钥，通过本机安全环境配置注入；不要提交到 Git 或粘贴到网页 |
| `GRADING_API_BASE` | HTTPS OpenAI 兼容接口，默认 `https://api.openai.com/v1` |
| `GRADING_MODEL` | 默认 `gpt-4.1-mini`，可换为供应商支持的模型 |
| `PORT` | 默认8000 |
| `HOMEWORK_DB` | 默认 `.data/homework.db`，可改为其他本机路径 |

供应商须支持 `/chat/completions`、JSON对象输出及所选模型。失败时不写入成绩。模型会收到原题、学生答案和评分依据，请先去除个人信息，费用与数据处理以供应商约定为准。实际供应商调用需你配置密钥后验证；自动化测试使用模拟响应，不代表真实模型精度。

## OCR 预留

网页可选择图片并检查接口，`POST /api/ocr` 当前明确返回 HTTP 501，不会假装已识别或上传到第三方。响应包含后续 multipart 图片上传和识别结果的契约；接入时须加入真实图片类型/10MB大小校验、OCR供应商适配及识别文本人工确认。当前学生需手动输入文字。

## 数据与测试

数据保存在 `.data/homework.db`，不提交到Git。关闭服务后可备份或删除该文件；重启服务保留历史错题。此版本是单机工具，同一电脑的使用者共享记录。

```bash
python3 -m unittest discover -s tests -v
node --check static/app.js
```

测试覆盖历史采分、七科输入、拒绝无依据猜分、否定语句待复核、精确判分、模型证据校验、HTTP复核分值校验、错题合并/筛选/导出、跨站写入拦截及OCR预留。Node只用于开发时检查JS，不是运行依赖。

完整历史示例见 [docs/history-example.md](docs/history-example.md)。
