# 拍照批改设置与使用

## Render中开启

1. 登录Render，打开 `homework-helper` 服务。
2. 进入 **Environment**，点击添加环境变量。
3. 填写以下配置并保存、重新部署；密钥只填写在平台安全设置，不发到聊天里、不提交Git。

| 名称 | 填写内容 |
| --- | --- |
| `GRADING_API_KEY` | 你从模型供应商获得的API密钥，必须有可用额度与图片模型权限 |
| `GRADING_API_BASE` | 供应商的HTTPS OpenAI兼容接口基地址；使用OpenAI时为 `https://api.openai.com/v1` |
| `GRADING_VISION_MODEL` | 支持图片输入和JSON对象输出的模型名称；OpenAI示例为 `gpt-4.1-mini` |
| `GRADING_MODEL` | 用于备用文字批改的模型名称；默认 `gpt-4.1-mini` |

`APP_PASSWORD` 是网页登录密码，和API密钥无关。模型供应商账号、API额度通常和聊天产品会员分开；服务可能按调用收费。不要随便购买不明来源的密钥。也可用其他供应商的兼容图片模型，但须先核对其接口是否支持 `image_url` 图片输入、`response_format` JSON对象输出与所选模型。

保存后等Render显示 **Live**，刷新网站。首页“拍照服务已配置”只说明变量存在，**不证明密钥、额度、供应商接口已经可用**。第一次上传实际照片成功返回报告才算真实链路验证通过。

## 直接拍照的操作

1. 在页面选择作业科目。
2. 手机点击“手机拍照”，或电脑点击“上传作业照片”。
3. 检查照片预览，确认原题和手写答案都清晰，再点击“开始拍照批改”。
4. 页面按题显示识别原文、判定、建议分值、解题步骤和弱项训练；无需事先手抄文字或填写采分点。
5. 检查识别文字和评分；点击“核对识别原文与评分”进入逐点评分复核。若OCR文字不对，可点击“识别有误，修改后重新批改”。

每次一张JPEG/PNG/WebP静态照片，不超过10MB、3000万像素、8题。整页太多题时请分区域拍摄。HEIC照片需转JPEG。照片在内存校验后发送给模型供应商；服务器不保存原图。识别出的题目与答案保存在错题记录中。供应商的数据政策、费用以其约定为准。

## 不强行判分

- 模糊字迹、原题缺失、图形条件不全、答案对应不清：单独提示重拍，不保存为已判错题。
- 模型评分检查分值求和与判定一致性、证据是否来自识别答案，全部结果仍待复核。
- 模型可能误识别字迹、图形与题号；即使输出分值校验通过，也不代表语义正确。
- 没有配置可用模型时，“开始拍照批改”不启用，文字版和历史例题仍可使用。
- 免费Render实例仍可能休眠、重启丢记录，及时导出。

## 当前验证情况

图片格式校验、超大输入限制、模糊题跳过、模型JSON结构校验、逐题归档及界面操作已通过模拟响应测试。**没有使用真实供应商密钥，因此真实照片的识别准确率、批改准确率和线上供应商连通性尚未验证。**

这是本仓库独立实现的拍照工作流；参考网站目前在开发环境中无法访问，因此尚未逐页对照复刻其界面、功能与效果。
