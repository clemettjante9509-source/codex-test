# 不安装软件，部署一次后直接打开网页

[点击一键部署到 Render](https://render.com/deploy?repo=https://github.com/clemettjante9509-source/codex-test)

1. 点击上面的入口，用 **GitHub** 注册或登录 Render。若仓库是私有的，按平台提示授权访问此仓库。
2. 页面会读取仓库里的 `render.yaml`。给 `APP_PASSWORD` 填写一个**至少12位的家庭访问密码**，只在 Render 的安全设置填写，勿发到聊天或提交 Git。然后点击 **Deploy Blueprint**（具体按钮文案以平台为准）。默认配置选择 Free；若平台要求付费、付款信息或升级，请先核对费用，不必购买付费方案才能试用这份代码。
3. 等服务状态变成 **Live**，打开平台给出的 **HTTPS 网站地址**。它才是你今后使用的网址，不是 `127.0.0.1`。
4. 浏览器提示登录时：用户名输入 **homework**，密码输入刚刚设置的 `APP_PASSWORD`。收藏网页后，电脑和手机都可以直接访问，不用下载代码。
5. 点击“载入历史例题”→“开始批改”测试。预期：2/4分，遗漏奖励军功，待复核。核对后可确认C类错误并导出错题清单。

## 免费方案的限制

- 免费服务可能闲置休眠，首次打开需等待唤醒；以平台当前政策为准。
- 免费方案没有持久磁盘。这份默认配置把SQLite放在临时目录；**重启、部署或实例替换后记录可能丢失**。请及时点击“导出考点 + 变式题”。导出的是学习清单，不是完整数据库备份，不能自动还原历史评分。
- 如果以后需要长期保存错题，可自行选购支持持久磁盘的方案，把磁盘挂到 `/var/data`，设置 `HOMEWORK_DB=/var/data/homework.db` 和 `STORAGE_PERSISTENT=true`，保留一个工作进程。先核对费用再升级；本仓库不会自动开通付费服务。
- 同一网站供同一家庭使用，所有知道密码的人共享错题本。没有独立学生账号。不要公开密码；更换密码后，之前知道旧密码的人将无法访问。

## 开启自动语义批改（可选）

不配置模型也可以用历史例题、教师采分点和客观题精确比对。要仅输入任意题目与答案后获得模型辅助报告，在 Render 服务的 Environment 页面安全配置 `GRADING_API_KEY`，以及可选的 `GRADING_API_BASE`、`GRADING_MODEL`。保存并按平台提示重新部署。主页会自动启用“模型辅助”选项。第三方模型调用可能收费，评分仍需复核。

## 排查部署问题

- 构建失败：查看 Render Logs；Python版本与依赖由仓库配置指定。
- 网站启动失败：确认 `APP_PASSWORD` 至少12位；不要把密码贴到聊天里。
- 域名不在允许列表：默认自动读取 `RENDER_EXTERNAL_HOSTNAME`；使用自定义域名时，在 `ALLOWED_HOSTS` 填入实际域名，多个以英文逗号隔开，不能包含协议或路径。
- 登录后无反应：使用平台提供的HTTPS地址；不要复制本机地址。
- 健康检查：`/health` 无需密码，仅返回状态，不返回错题或配置。其他页面及接口必须验证家庭密码。

代码和本机部署流程已经测试；一键入口只是部署入口，**还未在你的 Render 账号创建或发布网站**。上线完成后，以平台显示的网址及实测结果为准。
